## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

### Requirements

- Node.js 22.22.0+
- Yarn 1.22.22
- Installed `docker` and `docker compose` (optional)
- PostgreSQL database with name from `.env` `DATABASE_NAME` env variable

### Environment variables

Environment variables should be placed in `.env` file. You can check examples of env variables in `.env.example` file.

Application listening to `3000` port by default and accessible at `http://localhost:3000/`.

You can find swagger page with request / response examples at `http://localhost:3000/swagger`, 
swagger JSON - at `http://localhost:3000/swagger/json` page.

## Project setup

```bash
$ yarn install
```

## Compile and run the project

```bash
# development
$ yarn run start

# watch mode
$ yarn run start:dev

# production mode
$ yarn run start:prod
```

## Run in docker compose

```bash
# only postgresql service
$ yarn run docker:local

# all services
$ yarn run docker
```

## Migrations

```bash
# apply all migrations
$ yarn run migration

# create new migration (based on diff)
$ yarn run migration:create

# create intial migration
$ yarn run migration:initial
```
